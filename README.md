# ChaytAI Android releases

Official Android downloads and release notes for ChaytAI.

- [Google Play](https://play.google.com/store/apps/details?id=com.chayt.app)
- [Test APK for direct installation](https://github.com/beebuzzgrind-spec/chaytai-releases/releases/latest/download/ChaytAI-Test.apk)
- [Release notes](https://github.com/beebuzzgrind-spec/chaytai-releases/releases)
- [ChaytAI website](https://chaytai.com)

This repository contains release downloads only. Application source code, account data, and signing credentials are maintained separately.

ChaytAI Test installs separately from the production app and uses the same ChaytAI accounts. Test production Google Play purchases using the official app installed through Google Play. The production APK is Play-protected and may prompt manually installed copies to install from Google Play.
